## 为什么大家盯着"双 ISP 住宅 IP"

普通 VPS 给的是机房 IP：一整段地址被几百个用户共用，TikTok、Instagram、亚马逊、Netflix 的风控库早就把这些段收录了，你的机器刚开通，IP 可能已经在黑名单里待了很久。

住宅 IP 来自真实的 ISP 宽带线路，平台识别时看到的是"某个家庭在上网"。双 ISP 属性更进一步：IP 注册信息里同时挂着两个互联网服务提供商，特征更接近真实家宽，而不是一眼就能看出的数据中心地址。

丽萨主机新加坡这批 IP，官方说法是向 APNIC 新申请、十五年没被动过的全新段，Scamalytics 欺诈值 0。这个数字可以自己拿工具复测，不是只能听商家讲。

## 线路实话：三条线里只有一条是给国内用的

新加坡官方页面写得很直白：非大陆直连优化网络，建议通过香港或日本中转，香港延迟约 30ms，日本约 70ms；联通和部分地区移动直连效果还行。第三方 traceroute 也印证了这一点——电信方向去程要绕美国圣何塞、洛杉矶再到新加坡，延迟和丢包都不好看；移动回程经香港 CMI，情况好一些。它送的 5 个原生 IPv6 对中国移动方向有优化，移动用户直连 IPv6 大约 60ms，算是这条线的一个隐藏福利。

英国的情况类似但更明显：国内平均延迟 243ms，电信和联通去程绕美国、回程直连，移动去程回程都在绕；上传速度波动很大，有时能跑满 300Mbps，有时只有三四十兆。测评者本地联通看视频只有两万多的速度，勉强 1440P。商家的建议是中转，这个建议是诚实的。

CN2 GIA 是唯一例外，它的设计目标就是国内访问，六网回程全部走 GIA。

所以选之前先问自己一句：这台机器是给"平台"看的，还是给"人"用的。给平台看（TikTok 判定你是不是本地用户），选住宅 IP，中转一下无所谓；给人用（你自己天天连、客户打开网站），选 CN2 GIA，别为了省几十块去买非优化线路然后骂商家。

## 常见问题

**IP 真的是原生住宅 IP 吗？**
新加坡这批是向 APNIC 新申请的新段，官方标注十五年未使用、Scamalytics 欺诈值 0，可以自己复测；英国的两个 type 值都是 isp，欺诈值 0，属于双 ISP 住宅属性，但地址由 cogentco 机房承载。

**国内能直接连吗，延迟多少？**
新加坡、英国都不建议直连当日常代理。新加坡配香港中转约 30ms、日本中转约 70ms，联通和部分地区移动直连尚可；英国国内平均 243ms，路由绕行明显。要国内低延迟只有 CN2 GIA，全国平均约 172ms，晚高峰 150–180ms。

**TikTok 能用吗？**
新加坡套餐面向新加坡区 TikTok 运营，官方支持 Windows，方便跑自动化工具；英国套餐面向英国区 TikTok。账号能不能活，IP 只是其中一环，设备环境、操作行为同样重要，别把 IP 当万能药。

**买了不满意怎么办？**
48 小时内无条件退款，CN2 GIA 另有 2 元/天试用（试用版不退款）。

**能装 Windows 吗？**
新加坡和英国产品线明确支持 Linux 与 Windows，CN2 GIA 系列的系统选项以商品页为准。

**怎么付款？**
支付宝、微信、USDT、主流信用卡都行，国内用户直接支付宝，不用折腾汇率。

**优惠码能叠加吗？**
